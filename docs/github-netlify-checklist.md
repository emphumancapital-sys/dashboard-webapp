# GitHub + Netlify launch checklist

- [ ] Create Google Cloud project
- [ ] Enable Google Sheets API
- [ ] Create service account
- [ ] Share workbook with service account email as Editor
- [ ] Create GitHub repository
- [ ] Upload repository files
- [ ] Import GitHub repo into Netlify
- [ ] Set `GOOGLE_SHEET_ID`
- [ ] Set `GOOGLE_SERVICE_ACCOUNT_JSON`
- [ ] Set `JWT_SECRET`
- [ ] Set `BOOTSTRAP_ADMIN_USERNAME`
- [ ] Set strong `BOOTSTRAP_ADMIN_PASSWORD`
- [ ] Deploy and test login
- [ ] Confirm system tabs are created
- [ ] Confirm dashboard header mapping
- [ ] Restrict access to intended organization
